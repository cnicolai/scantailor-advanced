Scenarios (fixed here):
- Spread inputs: `PageSpec{SPREAD, dpi, seed 1, skewDeg 1.0}` for dpi 300 and 600; AUTO layout (it detects this spread correctly, research P3/P4); `outputDpi` 600; despeckle 1.0; `BLACK_AND_WHITE` (`_bw`) and `COLOR_GRAYSCALE` (`_color`). Image goldens `spread_<dpi>_<mode>_left` and `_right` (BILEVEL or COLOR); one text golden `spread_<dpi>_<mode>` with `layout_type`, `cutter_count`, `cutter_x1_px`, `cutter_y1_px`, `cutter_x2_px`, `cutter_y2_px` and, prefixed `left_` and `right_`, the per-page keys of plan 02-05's text goldens (`deskew_angle_deg`, content and page rect `_px`, hard margins `_mm`, output size `_px`, `output_dpi`), plus `seed`, `input_dpi`, `applied_skew_deg`.
- Split truth: `layoutType == 2` (TWO_PAGES) and one cutter; sample y every 10 input px from 0 to the image height; at each y the cutter's x lies within `gutterCentre` x(y) ± (`gutterHalfWidthPx` + 2). D-15 point check: |cutter x − gutter centre x| at mid-height ≤ 2 px (research measured about 7 px on a first fixture, so expect a D-18 mark; no Phase 3 to 6 requirement fixes page splitting, so the tag says `no requirement`). Each sub-page's deskew angle within the deskew tolerance of 1.0°.
- Dewarp input: `PageSpec{CURVED, 300, seed 1, skewDeg 0}`; layout `SINGLE_PAGE_UNCUT`; `BLACK_AND_WHITE`; `outputDpi` 600; run once with `dewarping = output::OFF` and once with `output::AUTO`. Straightness: `straightnessResidual(output, nonBackgroundBox(output), lineCount, 8)` on both outputs; both must be `valid`. Hard truth (D-04): residual(AUTO) < residual(OFF). D-15 check: residual(AUTO) x 300 / 600 ≤ 1.5 px. Golden `curved_300_dewarp` (BILEVEL, the AUTO output) and text golden `curved_300_dewarp` with `residual_off_px`, `residual_auto_px` (output pixels), `distortion_model_valid`, `output_w_px`, `output_h_px`, `output_dpi`.
- Fingerprints: text golden `fixtures` with keys `spread_300`, `spread_600`, `curved_300`.
- Sanity per output (D-05): as plan 02-05 (portrait, ink 0.5%..50%, line-band count ± 1 of the page's lines, margins within 5 mm), with width bounds from each sub-page's truth block; for the dewarp output, valid straightness results and ink 0.5%..50%.
