Character set (Claude's discretion in CONTEXT, fixed here): base names `a&b <c> "d" 'e'`, `Seite_ä_NFC` (U+00E4), `Seite_ä_NFD` (U+0061 U+0308), `x` (one character), and 100 repetitions of `Ü` in NFC (200 bytes of UTF-8), each with `.png`; input directory `in & <dir> "q" 'a'`, output directory `out & <x> "y"`. APFS treats NFC and NFD forms of one name as the same file, so the two umlaut names differ in their suffix and never collide. Each file is a small generated PNG (64 x 64, RGB32, 300 dpi in the metadata) written with `QImage::save`.

Non-default parameters: set through the public `DefaultParams` setters (`src/core/DefaultParams.h`: `FixOrientationParams`, `PageSplitParams`, `DeskewParams`, `SelectContentParams`, `PageLayoutParams`, `OutputParams`), installed with `DefaultParamsProvider::setParams(std::move(params), "RoundTrip")`, then applied with `filter->loadDefaultSettings(pageInfo)` for every page and every filter of a `StageSequence`. Pick at least one changed value per stage that a user can enter in the UI (at most two decimals), for example: rotation 90°; layout SINGLE_PAGE_UNCUT in manual mode; manual deskew 1.25°; page detection on with fine-tuned corners; hard margins 7.5 / 8.25 / 9 / 10.5 mm and top-left alignment; output colour mode MIXED, DPI 400, despeckle level 2.0, dewarping AUTO, depth perception 2.5. Read `DefaultParams.h` and choose setters that exist; record the chosen values per stage in the records file.
