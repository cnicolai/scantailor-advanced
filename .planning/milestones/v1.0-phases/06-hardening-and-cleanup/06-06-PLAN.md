## Decisions recorded by this plan

- **Multi-page files at creation (D-04 interpretation):** a file with at least one oversized page is refused as a whole in the project file dialog and in the insert flow, and the text names the page (`page 2 too large: ...`). The dialog adds whole files, and the project model has no way to leave out one page of a file. Inside an existing project (a project from an older version, or a file replaced on disk) the reader refuses only the oversized page and the other pages load (plan 06-04). Both places use the same `ImageSizeLimit::exceeds`, so creation and loading agree on the limit.
- **Box wording (CONTEXT discretion):** the existing "Some of the files failed to load. ..." text stays byte-identical; when a too-large file is in the list, the line `Files marked "too large" exceed the image size limit of 65535 px per side and 537 megapixels in total.` is appended after it.
