<objective>
Prepare the end-to-end smoke run without launching the app: measure the device pixel ratio and the real settings paths with a scratchpad probe, generate the throwaway pages, and get the user's D-02 decision on any leftover ScanTailor settings, using the corrected paths.

Purpose: BUILD-03's smoke run (plan 01-06) needs input pages and a known settings state. D-01/D-02 assumed a plist in `~/Library/Preferences`, but `src/app/main.cpp:47` sets `QSettings::IniFormat`, so the settings file is an INI under `~/.config` (research Pitfall 1, Open Question 1). 01-CONTEXT.md records this as "Amendment 2026-10-18" under D-02: the storage wording of D-01/D-02 is superseded, their intent is unchanged, and the exact paths come from this plan's probe. The permission request must name the paths the app really uses. The probe also gives the Phase 4 Retina measurement (D-06, HIDPI-01) without any committed code change.
Output: `records/probe-output.txt`, `records/smoke-pages.md`, `records/prior-state.md`; pages and probe in the session scratchpad only.
</objective>

Probe (D-06). In `{scratch}/dpr-probe/` write a `main.cpp` and a `CMakeLists.txt` that builds a plain executable (no `MACOSX_BUNDLE`, so it is unbundled like the app) against `Qt6::Widgets`. The program creates a `QApplication`, sets application and organisation name to `scantailor-advanced` (the values of `APPLICATION_NAME` and `ORGANIZATION_NAME`), shows a 300 by 200 `QWidget`, and after 500 ms prints, one item per line: for every `QScreen` its name, `devicePixelRatio`, `logicalDotsPerInch`, `physicalDotsPerInch` and geometry; the widget's `devicePixelRatio`; `QLibraryInfo::build()`; `QDir::homePath()`; the value of `XDG_CONFIG_HOME` (or `unset`); the derived INI path; and `QStandardPaths::writableLocation(QStandardPaths::AppDataLocation)`; then it quits. Derive the INI path with Qt's documented rule for `IniFormat` and `UserScope` on macOS: `XDG_CONFIG_HOME` (or `$HOME/.config` when unset) + `/scantailor-advanced/scantailor-advanced.ini`. The probe must not construct a `QSettings` object: its constructor reads the INI file, which would touch the user's settings before the D-02 permission (threat T-01-12).

Build it with `cmake -S {scratch}/dpr-probe -B {scratch}/dpr-probe/build -G Ninja -DCMAKE_PREFIX_PATH=/opt/homebrew` and run it from the executor's shell (a small window opens for half a second in the user's session). Write the output to `records/probe-output.txt`, followed by the line `probe constructs QSettings: no` after checking its source with grep. If the Cocoa platform cannot start from this shell, record the error, run it again with `QT_QPA_PLATFORM=offscreen` for the paths only, and write `DPR: to be measured in plan 01-06 step 1 (QT_LOGGING_RULES)`.

Pages (D-04), with `magick` only, no fonts (no `-annotate`, no `-font`; a system font path would be outside the project), into `{scratch}/smoke/pages/`. "Text" is rows of small filled black rectangles 28 px tall with widths from a fixed arithmetic sequence between 30 and 140 px and 14 px gaps (no random generator), row pitch 70 px.
- `01-flat-text.tif`: 2480 by 3508 px (A4 at 300 DPI), white, about 36 text rows inside 250 px margins, then the whole page rotated by 1.5 degrees on a white background and cropped back to 2480 by 3508 (a deskew target).
- `02-book-spread.tif`: 4960 by 3508 px, white, a 60 px grey (#808080) gutter band centred on x = 2480, text rows on both halves (250 px from the outer edges, 200 px from the gutter), then `-wave` with amplitude 30 px and wavelength 9920 px on a white background so every row curves, then extended back to 4960 by 3508 around the centre.
- `03-mixed.tif`: 2480 by 3508 px, white, about 20 text rows in the top 45 percent, a 1400 by 1000 px colour block centred in the lower half built from ImageMagick's `gradient:` and `radial-gradient:` generators in at least two strong colours (no `plasma:` or other random generator), and about 10 text rows below it.
Every page gets `-density 300 -units PixelsPerInch`, 8-bit depth and LZW-compressed TIFF output; the density keeps ScanTailor from asking for a DPI (research A8). Create `{scratch}/smoke/out/` empty.

Write `records/smoke-pages.md`: a title; the purpose (D-04: throwaway, never committed; Phase 2 builds the real seeded generator); the location `{scratch}/smoke/pages`; the exact `magick` command lines as run (normalised); the output of `magick identify -format '%f %wx%h %x %y %U %[colorspace] depth=%z\n'` for all three pages; the `shasum -a 256` of each; and a `## Regenerate` note telling plan 01-06 to rerun the same commands if the scratchpad no longer holds the pages.
