- `## Findings in project code`: a table with kind (for example `heap-buffer-overflow`, `signed-integer-overflow`, `misaligned address`), location (the first stack frame under `{repo}/src/`, as `file:line`), count, test executable, and the first report line.

- `## Totals`: total ASan reports, total UBSan reports, number of distinct project locations, and per-executable counts. If there are none, write `0` for each with the grep commands that produced the zeros.
