2. Write `build/scratch/prune/prune.py` (scratch only, not committed; `python3 -I`, standard library). Input: a list of files. For each file it collects the `#include` lines and classifies them: never removed are the file's own header (the include whose base name equals the file's base name, or for the two headers the class header they declare), `config.h`, `version.h`, standard library headers (angle brackets, no `.` in the name, not starting with `Q`), and every include whose base name (file name without directory and extension, for example `QTimer`, `BinaryImage`, `bind`) occurs as a whole word in the file outside the include lines. The rest are candidates. For each candidate in file order it removes the line and runs the syntax-only compile with the Release and with the Debug compile command of the file (command from the compile database with `-o <obj>` and `-c` replaced by `-fsyntax-only`; for a header: compile a scratch translation unit that contains only `#include "<header path>"`, using the flags of one `.cpp` that includes it, and also every `.cpp` that includes the header); it keeps the removal only if every compile exits 0 and prints no warning that the baseline compile did not print; otherwise it restores the line. It logs each decision to `build/scratch/prune/<file>.log`. Run it on the two headers first, then on the four `.cpp` files, in the background.
3. Rebuild (`cmake --build --preset macos-release`), copy the four new objects to `build/scratch/prune/after/`, disassemble them the same way and compare each pair (`diff` of the `.dis` files without their first line). Every pair must be identical. If a pair differs, restore the original include list of that `.cpp` (`git checkout -- <file>`) and of the headers it includes, rebuild and compare again until all four match; note each restored file.
4. Format the six files (convention 4; clang-format may regroup includes, which is fine as long as the disassembly comparison of step 3 is repeated after formatting). Also build Debug (`cmake --build --preset macos-debug`) to be sure the Debug-only paths still compile.
