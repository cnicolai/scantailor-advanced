# Phase 06.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| source edit → compiled program and output pixels | Comment rewrites, include pruning and the undefined-behaviour fixes must not change compiled code or output | Source text |
| image file on disk → own-file readers | A forged header of a cached output file decides allocation sizes | TIFF headers |
| harness arguments → file system | `ui_snapshot`, `retina_check` and `mac_check` write into a caller-given directory | Path strings, command-line flags |
| CMake cache variable → compiler command line | `SANITIZE` is pasted into every compile and link command | Cache value |
| sanitizer report → test verdict | A report inside a passing test must fail the run | Runtime reports |
| build-file edit → build commands | Preset and flag-block edits could alter the default build | Compile and link commands |
| records → repository history and phase verdict | Dispositions, gate log and closing evidence carry the claim that nothing is open | Record text |
