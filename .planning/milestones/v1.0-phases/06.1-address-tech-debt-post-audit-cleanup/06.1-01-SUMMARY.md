- Test first: `testNoOpenGlInSourcesOrBuild` reads `.claude/CLAUDE.md` through `readUtf8(root.filePath(...))`, requires it to be non-empty and requires it not to contain the word in any letter case. The red run (`build/scratch/qt-t01-red.txt`) failed with `.claude/CLAUDE.md names OpenGL` at `tst_mac_qt.cpp(1773)`; the green run (`build/scratch/qt-t01.txt`) passes with four `Totals:` lines, all `0 failed`.

A case-insensitive `git grep` over the three files prints nothing.
- Gate `t01-opengl-doc` (commit `a9c698c0`): Release and Debug `100% tests passed out of 7`, goldens unchanged, both `diff_lines=0`. The row is in `records/gate-log.md` (commit `cd68982c`).
- `records/token_diff.py` (commit `529d4b2c`): pairs removed and added lines by output file (`-o` token, else the token after an `ar` mode argument), prints `CHANGED`, `reordered`, `ONLY-REF`, `ONLY-NEW` and a token-count summary; exit 2 on bad arguments or a missing file. On the t01 gate lists it reports changed=0 ref-only=0 new-only=0.
