| Property | Value |
|----------|-------|

| **Config file** | `CMakePresets.json` (test presets `macos-release`, `macos-debug`, `macos-asan`; new `macos-asan-collect`), per-suite `add_test` in `src/*/tests/CMakeLists.txt` |

| **Estimated runtime** | quick ~10–60 s; gate ~6–8 min; strict `ctest --preset macos-asan` ~11 min |

---

## Sampling Rate

- **After every task commit:** `xcrun clang-format --dry-run -Werror` on touched C++ files; `gate.sh check <label>` for any commit touching `src/`, a CMake file or `CMakePresets.json` (docs-only commits need no gate)
- **After every plan wave:** all gate rows of the wave green and recorded in `records/gate-log.md`
- **Before `/gsd-verify-work`:** one full strict `ctest --preset macos-asan` green, closing greps empty, zero `open` dispositions
- **Max feedback latency:** ~480 seconds (one gate run)
