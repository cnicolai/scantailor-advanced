## Sampling Rate

- **After every task commit:** `xcrun clang-format --dry-run -Werror` on touched C++ files; `gate.sh check <label>` for any commit touching `src/`, a CMake file, `CMakePresets.json` or `.claude/CLAUDE.md` (read by `qt_tests`); docs-only commits need no gate, and 06.1-15 proves each of them has its parent's gate input key
- **After every plan wave:** all gate rows of the wave green and recorded in `records/gate-log.md`
- **Before `/gsd-verify-work`:** one full strict `ctest --preset macos-asan` green, closing greps empty, zero `open` dispositions
- **Max feedback latency:** ~480 seconds (one gate run)
