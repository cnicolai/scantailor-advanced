Ten files (two CMake files, eight app and harness sources) lost every phase, decision, plan and review-finding number in their comments in favour of the plain reason each stood for, proven comment-only by the new `records/comment_only.py` and by two gates with empty command diffs; this closes Phase 4 IN-04.

## Accomplishments

- `records/comment_only.py` (`python3 -I`, standard library) compares the comment-free token streams of `git show <rev>:<file>` and the working file. C, C++ and Objective-C++: `//` and `/* */` comments, string and character literals with escapes, raw strings and digit separators. CMake: `#` comments, bracket comments, quoted and bracket arguments. `--strings` replaces literal contents by a placeholder.
- Positive controls (`build/scratch/comment-only-controls.txt`): unchanged file EQUAL; a changed CMake target name and a changed `return` token DIFFERENT; a comment-only edit EQUAL in CMake and C++; a changed string literal DIFFERENT in plain mode and EQUAL in `--strings` mode.
- `src/app/CMakeLists.txt` and `src/test_support/CMakeLists.txt`: seven comments rewritten, including the `RESEARCH Pitfall 2` reference (now "names the application menu items after the app instead of the process"). Commit `3f155d41`, gate `t09-comments-build` PASS.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] comment_only.py wrote NUL bytes into its difference report**
- **Found during:** Task 2 verification (the controls file could not be searched: ugrep treated it as binary and `grep -q DIFFERENT` failed)
- **Issue:** whitespace inside a string-literal token was escaped as a NUL byte plus two hex digits, so the printed token context contained NULs.
- **Fix:** whitespace is now escaped as the printable text `\x20` (a backslash in a literal is doubled); comparison semantics are unchanged. Controls and both proofs were rerun with the fixed script; all results are as before.
- **Files modified:** `records/comment_only.py`
- **Commit:** `4a1b287d` (docs only, not gated)

**Total deviations:** 1 auto-fixed (Rule 1). **Impact:** none on the committed comment edits; the earlier EQUAL results were semantically the same.
