# Phase 06.1 Plan 06: Own-file ceiling and own-file loader Summary

Files the application wrote itself are now read with a fixed header ceiling (fewer than 2^30 px, at most 131070 px per side) instead of no limit, the unlimited `ImageLoader::load(const ImageId&)` overload is gone, the remaining own-file readers are called `loadOwnFile`, and a forged header at the cached output name makes the page regenerate.

## Accomplishments

- Own-file ceiling (D-11, tracer): `ImageSizeLimit` gains `kMaxOwnFilePixels`, `kMaxOwnFileSide`, `enum class LimitKind { SOURCE, OWN_FILE }`, `exceedsOwnFile` and `exceeds(size, kind)`, with two `static_assert`s and a doc comment that derives the value (500 mm at 1200 dpi is 23622 px, about 558 Mpx for a square page; the ceiling is about 1.9 times that). `TiffReader::readImage` and `ImageLoader::loadImpl` take a `LimitKind` instead of the old boolean, so no reader of an own file is unlimited any more. The same commit documents the 16-bit PNG case of Qt's allocation limit (Phase 6 IN-02), uses the multiplication sign in the header comment (IN-03) and rewrites the two planning references.
- New loader cases: `test_forged_own_tiff_is_refused_without_allocating` (100000 x 100000 bilevel), `test_forged_own_rgb_tiff_is_refused_without_allocating` (40000 x 40000 RGB), `test_own_file_inside_the_own_ceiling_parses` (header-only: 131070 x 8192 is inside the own ceiling and above the source limit, plus a table of edge sizes), and the renamed `test_own_files_use_the_own_ceiling_and_source_files_the_source_limit`. Suite: 20 cases, no errors.
- Mutation proof: with `exceedsOwnFile` returning false the forged own-file case fails on `image.isNull()` and on the footprint (growth 1250673552 bytes against the 64 MB bound); restored with `git diff` showing no `return false`.
- Loader names (D-12): `load(const ImageId&)` deleted (no caller); `load(const QString&, int)` and `load(QIODevice&, int)` became `loadOwnFile`; six calls in `output/Task.cpp`, one each in `ThumbnailPixmapCache.cpp`, `HeadlessPipeline.cpp` and the test helper renamed. `git grep -E 'ImageLoader::load\('` prints nothing; `ProjectFilesDialog.cpp` uses the multiplication sign (IN-03). The `needReprocess = outImg.isNull();` logic is unchanged.
- Regeneration through the real output stage (D-11 test clause): `PipelineOptions::beforeOutputRerun` runs the chain a second time on the same project. `test_forged_cached_output_is_regenerated` replaces the output by a forged 100000 x 100000 header padded to the stored byte size (the cache check compares the byte size only, and the case asserts that the cache accepts it), and the page comes back identical to the first output. Control `test_valid_cached_output_is_read_back` puts a valid 16 x 16 TIFF at the same name and gets 16 x 16 back, so the regeneration comes from the refused load. Mutation `needReprocess = false` made the forged case fail; the ceiling was never switched off here.
- Gates: `t06-own-ceiling` (`d9a32fd9`), `t06-own-loader` (`afcaa7ee`), `t06-own-regen` (`26451961`) all PASS, Release and Debug `100% tests passed out of 7`, goldens unchanged, command diffs empty (0 / 0).
- Dispositions: Phase 6 IN-02, IN-03, IN-04, IN-05 are `fixed`; the file reads `open: 2 counted 2` (IN-01 closes in 06.1-08, IN-06 in 06.1-07).

## Deviations from Plan

**1. [Rule 1 - Bug] The forged-own helper failed on its own precondition, so the mutant did not exercise the loader**
- **Found during:** Task 1, mutation run
- **Issue:** The first version of `checkOwnFileRefusedWithoutAllocating` used `BOOST_REQUIRE(ImageSizeLimit::exceedsOwnFile(...))`. With `exceedsOwnFile` mutated to return false, the case stopped at that precondition and never reached the loader, so the mutation did not show that the loader enforces the ceiling.
- **Fix:** The precondition is a `BOOST_CHECK`, so the mutant run goes on to the load and fails on the non-null image and the 1.25 GB footprint growth, as the plan expects. This is the allocation the plan sanctions for the bilevel forgery; the RGB forgery was never run without the ceiling.
- **Files modified:** `src/core/tests/TestImageSizeLimit.cpp`
- **Commit:** `d9a32fd9` (fixed before the commit)

**Total deviations:** 1 auto-fixed (Rule 1). **Impact:** none on scope or output.
