## Explanation of every changed token

+ -Wall                 added, commit e35b498 (D-08): Clang counterpart of the GNU warning set at CMakeLists.txt:45; warning only, no code generation change.
+ -Wextra               added, commit e35b498 (D-08): same.
+ -Werror=return-type   added, commit e35b498 (D-08): turns a missing return into an error; no code generation change for code that compiles.
+ -Wno-unused           added, commit e35b498 (D-08): silences unused-variable/function warnings, as the GNU set does.
+ -ffp-contract=off     added, commit 606bea0 (D-03): freezes floating-point contraction; see fp-contract.md. This is the one added token that changes generated code, on purpose and before any baseline exists.

## Tokens checked that did not change

-std=gnu++17 is present on both sides (no CMP0128 effect), no extra -isystem Boost path appeared (the Boost bridge was not needed, fix-log.md '## Checked, not changed'), -O3, -DNDEBUG, -DQT_NO_DEBUG, -arch arm64 and every other -D, -I, -isystem and -f token are identical. There is no unexpected changed token (A12), so nothing was stopped for a question.
