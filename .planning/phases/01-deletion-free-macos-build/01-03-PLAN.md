- the full `otool -L build/macos-release/scantailor-advanced`, then one line per library with the count of load-command lines matching `libjpeg`, `libpng` and `libtiff`. Each count must be exactly 1: zero fails just as two do (edge truths).

- the compile_commands flag check for the release tree (the jq command from plan 01-01 Task 2), with its printed counts.

If a library count is not 1, find the cause from the configure output (`cmake --preset macos-release --fresh` prints the found JPEG/PNG/TIFF paths) and fix it only through preset cache variables in `CMakePresets.json` (for example the `JPEG_LIBRARY_RELEASE`/`JPEG_INCLUDE_DIR` cache entries pointing at the `brew --prefix jpeg-turbo` paths), never through source or by uninstalling a formula. Commit such a preset change on its own with the reason, rebuild, and re-run the checks. If the duplicate comes from a Homebrew dependency itself, record it and stop with a report.
