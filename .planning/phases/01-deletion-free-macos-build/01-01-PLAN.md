## Conventions for every record in this phase

- Records directory: `.planning/phases/01-deletion-free-macos-build/records/` (called `records/` below). Create it in Task 1.
- Use only `.txt`, `.md`, `.xml` or `.json` names. `*.log` is gitignored (`.gitignore:155`), as are directories named `Testing` or `test_results`. Before each records commit, `git check-ignore -v <file>` must print nothing.
- Capture, do not summarise from memory: redirect the real command output into the record (RESEARCH Pattern 3).
- After capturing, normalise paths in the record: replace the absolute checkout root with `{repo}`, then `$HOME` with `~`, then the session scratchpad path with `{scratch}` (BSD `sed -i ''`). This keeps records stable across worktrees and keeps the home path out of git.
- Long commands (brew install, builds) may exceed the 10-minute tool limit. Run them in the background and wait for completion rather than cutting them short.
- Global rule: never list or read directories outside the project (`/opt/homebrew`, `~/Library`, `~/.config`). Use the `brew` CLI and the installed tools only; CMake reading Homebrew packages during configure is the build tool's own access and is expected.
